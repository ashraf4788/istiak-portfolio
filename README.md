# UI/UX Designer Portfolio - Next.js Website

A premium, modern, and visually engaging personal portfolio website built with Next.js, Tailwind CSS, and Lucide React.

## Color Palette
- **Primary Green:** `#2C8C68`
- **Dark Background:** `#17231F`
- **Light Green Background:** `#F2F8F3`
- **White:** `#FFFFFF`
- **Soft Neutral Background:** `#F7F9F7`

## Features Included
1. **Sticky Navigation Bar** with smooth scroll and mobile menu drawer.
2. **Hero Section** with availability badge, metrics, and creative visual card.
3. **Dedicated About Me Section** with background story, design philosophy, and resume CTA.
4. **Selected Works Portfolio** featuring 4 detailed case study cards and interactive modal popups.
5. **Design Process Workflow** (5 structured phases from research to refinement).
6. **Skills & Expertise** categorized skill cards and software toolchain.
7. **Services Section** covering UI/UX, Web, Mobile, Landing Pages, and Design Systems.
8. **Contact Section** with validated inquiry form and success toast state.
9. **Footer** with navigation and copyright.

## Getting Started

1. Unzip the project folder.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
